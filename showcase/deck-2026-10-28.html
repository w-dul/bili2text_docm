01 · 背景与主线

两个背景，一条主线

背景 1 · 为什么用打字练习

视频是结构化的学习资源

为了方便记忆，我们把它转成系统化的文本，再通过打字练习反复多遍输入：逐字敲一遍原文，节奏自然放慢，内容在重复中被梳理，理解也更充分。

背景 2 · 工具现状

有文本，但不好用

现有流程能把 B 站视频转成逐字稿，但转写结果存在同音字、断句和标点错误，拿到文本后缺少低成本的修正手段；逐字稿页面以「看」为主，没法把素材变成可反复练习、可量化的输入内容。

02 · 功能与界面

首页：链接进来，逐字稿出去

127.0.0.1:8000/

首页：提交区 + Videos 列表，当前工作区共 4 条视频。

  • R1

    一条链接即可提交

    粘贴 B 站链接、BV 号或本地音视频路径；每行一条，即批量提交。

  • ENGINE

    转写引擎可选

    whisper 与 sensevoice 两个 provider，模型默认 large-v3-turbo；转写提示词（glossary）可选填。

  • STATUS

    任务页实时展示阶段

    提交后进入任务页，下载、转写各阶段的进度与消息实时推进，完成后直接进逐字稿。

bili2text · 项目展示
首页只有一件事：把链接交出去。多行输入就是批量任务，这是 P0 已有能力，不是规划。

02 · 功能与界面

逐字稿：双栏，版本可切

127.0.0.1:8000/videos/4

左栏操作与分段，右栏正文；顶部标注当前激活版本与分段数量。

  • R2

    三个版本共存

    原稿 original、人工编辑 edited、AI 修正 ai_corrected；同一时间只有一个激活版本，可切换与下载。

  • R4

    激活版本自动分段

    按句末标点切分，单段 120–300 字；超长句二次切分，尾部过短合并，拼接可还原原文。

  • EDIT

    正文可直接改

    保存后生成新版本并激活，原版本保留，不会覆盖历史。

34当前激活版本分段数
3版本类型
4工作区视频数
bili2text · 项目展示
这一页是三件事叠在一起：版本管理、分段、可直接编辑。34 段是视频 4 的实测值。

02 · 功能与界面

LLM 修正：先看差异，再决定

/videos/4/correction/7cea8bc9

修正预览：左侧原文、右侧修正稿，下方整篇可手动再改。

  • R3

    手动触发，分块请求

    设置页配置 OpenAI 兼容接口后手动发起；长文按 1500 字分块，只纠错不删减。

  • DIFF

    差异预览后应用

    应用即生成 ai_corrected 版本并激活；也可放弃，原文不受影响。

  • SAFE

    失败可重试、可取消

    任务失败保留错误信息，修正过程可随时取消，不会留下半成品版本。

02 · 功能与界面

练习选择：按内容挑段，或直接贴文本

/videos/4/typing

段落卡片显示正文前 80 字，复选框可多选；下方是粘贴自定义文本区。

  • R5

    按正文挑段，不只看段号

    每段卡片带正文预览与字数，勾选一段或多段后开始练习。

  • MULTI

    多选按段拼接

    多段练习保留原段落结构，按「第 1 段 / 第 2 段 …」分块显示；只选一段则走原单段页。

  • CUSTOM

    也能练项目外的文本

    粘贴任意文本（≥10 字）即可开始，记录以 mode=custom 保存，不污染段落完成状态。

02 · 功能与界面

练习页：逐字模式，错了也能往下走

/videos/4/typing/5/1

上方原文逐字对照，下方输入区与进度、CPM、正确率、错误字符实时统计。

  • P6

    错字标红占位，不阻断

    输错字符保留占位并标红，光标继续推进；正确率按已输入字符核算。

  • P7

    标点自动跳过

    标点灰显、不计入进度与正确率；英文大小写不敏感，输入全小写或全大写均判对。

  • STAT

    四个数字实时更新

    进度、每分钟字符数（CPM）、正确率、错误字符；完成后记录留存。

02 · 功能与界面

设置：只配一次，保存即生效

127.0.0.1:8000/settings

上半部分是转写引擎信息（来自启动配置），下半部分是 LLM 修正配置。

  • LLM

    OpenAI 兼容接口

    填写 Base URL、API Key、模型名、请求超时即可；可选全局术语表，避免专有名词被改错。

  • TEST

    保存前可测连接

    「测试连接」验证配置可用；API Key 保存后只显示尾号，不会写入日志或任务事件。

  • OFFLINE

    不配也能用

    未配置时仅修正功能不可用，转写、分段、打字练习不受影响。

bili2text · 项目展示
设置页是修正功能的前置条件。Key 只存本地，页面上只回显尾号，这是 P0 就定下的处理方式。

03 · 版本演进

需求边界：七条需求，四条不做

R1

链接转写

链接提交，后台下载音频并转写，任务页实时展示阶段与进度。

R2

版本管理

原稿、人工编辑、AI 修正三版本；同一时间只一个激活版本。

R3

LLM 修正

手动触发，1500 字分块，只纠错不删减，差异预览后应用。

R4

自动分段

R5

打字练习

分段或多选段落、粘贴文本；逐字对比，统计 CPM、正确率、错误字符。

R6

页面结构

首页、任务页、逐字稿双栏、设置页、练习选择页与练习页。

R7

独立知识库站点，承载使用说明、背景与基础知识。
